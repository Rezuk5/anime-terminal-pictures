`functional.py` занимаеться записью изменений настроек пользователя а так же получением рандомных изображения 

класс `GetRandom` занимаеться назождением случайного изображения по настройкам пользователя и возращением пути до изображения 

класс `setRandomMod` принемает и записывает пользовательские настройки мода

функция `set_config` принемает путь к изображению и устанавливает его в конфиг `configs/fastfetchConfig.jsonc` который занимаеться отрисовкой изображения и статистики в терминал 


install.sh автоматичиски устанавливает все зависимости обновляет нудные файлы для работы скрипта и делает .sh файлы исполняемыми. Работает на arch linux
