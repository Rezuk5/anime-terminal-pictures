Anime Terminal Pictures (atp) - Это утилита что бы урасить свой терминал и сделать свой конфиг более разнообразным. Выводит в терминал аниме картинку с системным состоянием. Уже с коробки собраны более 200 картинок из пп тайтлов приемущественно аниме вайфу. Много гипких настроек: есть возможность установить слуйчайный выбор картинки, выбраную картинку, случайный выбр из выбранного тайтла / своей папки, случайный выбор по имени персонажа, так же ставить статичную картинку. Все это настроиваеться под себя и конечно же есть возможность самому вводить изменения.

Подрузумевает использование в терминале Kitty тк многие другие терминалы не поддерживают фотографии.

использование:
взаимодейсвие через графичиский интерфейс:
для открытия графичиского интерфейса используйте команду atp gui
после открытия будет дано 4 выбора
1) все арты - Нужен для выбора статичной картинки. Выведет все картинки для выбора каторые лежат во вложенных директориях в AnimePictures и data/CustomSet. Выбраная картинка будет установленна как статичная при вводе команды atp
2) Сортировка - Нужен для выбора статичной картинки. Сначало выводит не картинки, а директории в которых они лежат, после выбора директории так же можно будет выбрать интересующую картинку, после чего она станет статичной при вводе atp
3) Random Mode - Нужен для установки рандом режима при котором atp каждый раз выводит разные картинки. В нем есть 2 вида раздела:
1 устанавливает AllMod выборку из всех картинок которые лежат в AnimePictures
2 Это выбор по названием папок, обычно название тайтлов, устанавливает userMod, из выбранной папки будут случайно выбираться изображения при вводе команды atp
3) Name Presets - Дает выбор директории по названию тайтлов и тд. Выбраная дериктория сортируется по именам персонажей. Все изобродения выбранного персонада будут случайно выбираться при вводе команды atp. Чуствителен к случайным именнам изображений

взаимодействие с утелитой происходит через atp:
atp - выводит картинку c системным состоянием. Я советую использовать ее автомотичиски при открытии терминала для этого ее можно добавить в .zshrc файл если вы используете zsh
atp gui - открывает gui для визуального взаимодействия с утилитой
atp setPicture "путь к картинки" - устанавливает ваше статичное изображение
atp setAllMod - мод при котором будет выводиться случайная картинка из списка data/dataPictures.txt 
atp setUserMod "путь до папки" - мод при котором рандомная картинка будет выбираться из выбранной папки
atp setUserMod "путь до папки" "имя персонажа" - мод при котором будет выбирать рандомная картинка определенного персонажа. Имя персонажа должно быть написано в названии файла картинки до цифр и формата
apt updateData - обновляет список для выбора рандомных картинок если пользователь менял /AnumePictures
apt randomGen - не нужна в обычном использовании, но при в ключенном рандом моде генерирует новую случайную картинку не выводя ее. При использовании atp это происходит автомотически 


Добавление/удаление и взаимодейсвие с наборами картинок просходит в /AnimePictures и data/CustomSet 

/AnimePictures подрузумевает храниние папок с названием тайтлов аниме или же своих сборок. Все фото в этих файлов используеться в режиме setAllMod тоесть могут быть выбраны случайны 

data/CustomSet так же хранит папки с фотографиями, но эти фото не могут быть выбраны в режиме setAllMod. Здесь можно собирать свои наборы из только интересующих красивых фотографий или же по каким-то определеным параметрам и при этом эти сборки могут быть использованы в setUserMod тоесть случайно выбираться из выброной папки. Подрузумеваеться хранение сборок в каторых фотографии могут быть скопированы из /AnimePictures и просто храниние фото в которых вы мало заитересованы но иногда нуждаетесь.
